## Мета

Навчитися використовувати *Git* для керування версіями проєкту та працювати з віддаленим репозиторієм на **GitHub**.

## Що зроблено в лабораторній роботі №1

1. Створено локальний репозиторій і перший коміт.
2. Додано стилі в окремій гілці `new-feature` та злито її в `main`.
3. Опубліковано проєкт на GitHub.
4. Зміни внесено через pull request.

## Основні команди

```bash
git init -b main
git checkout -b new-feature
git merge --no-ff new-feature
git push -u origin main
```
